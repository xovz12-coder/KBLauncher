Версия 0.2.42 · Nightly 38609b7

5 ноября 2026

🚀 Новое в KBLauncher

  • Полный ребрендинг в KBLauncher с новым 3D-логотипом и обновлённой темой оформления.
  • Поддержка косметики: значок основателя KBLauncher возле никнейма в игре.
  • Отображение плащей и косметических предметов в одиночной игре.
  • Быстрый установщик нативных модов напрямую по ссылке с GitHub репозитория.
  • Интеграция менеджера локальных серверов с автогенерацией настроек и EULA.

🛠 Исправления и оптимизация

  • Realms: экран конфигурации владельца и вкладка подписок.
  • Windows: предотвращены повторные запросы брандмауэра при обновлениях лаунчера.
  • Оптимизировано выделение оперативной памяти Java при запуске тяжёлых модпаков.
