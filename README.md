# KBLauncher

Современный и атмосферный лаунчер для Minecraft в стиле **Retro Synthwave & Glassmorphism**, воссозданный по скриншотам с новым 3D-логотипом **KBL**.

## ✨ Особенности и функции

- **Новый 3D-логотип KBL**: Интегрирован на окно приложения, заголовок, аватарку сборки и карточки.
- **Оригинальная цветовая палитра и арт**:
  - Пиксельный закат с солнцем и силуэтом соснового леса.
  - Полупрозрачные карточки с эффектом матового стекла (`backdrop-filter: blur(20px)`).
  - Насыщенные индиго/фиолетовые акценты (`#6366f1`).
- **Кастомная безрамочная панель управления окном**:
  - Сворачивание, разворачивание, закрытие.
  - Поддержка перемещения (drag-and-drop) окна.
- **Вкладка «Главная»**:
  - Статистика онлайна: *«Вы наиграли 5 мин! Последняя игра: вчера. · 1,168 сейчас в игре · 128,490+ скачиваний»*.
  - Большая кнопка **«▷ Играть»** с полным циклом запуска (Подготовка -> Загрузка -> В игре с PID).
  - Выбор версий игры (Nightly · 38609b7, 1.21.4, Fabric 1.20.1, Forge, NeoForge, OptiFine).
  - Поле быстрого подключения по коду друга (*«Вставьте код приглашения друга»*).
  - Подвкладки: **Обзор** (Скриншоты + Журнал изменений), **Моды**, **Миры**, **Сетевая игра**, **Наборы**.
- **Вкладка «Моды»**:
  - Каталог популярных модов (Sodium, Iris, Fabric API, Lithium, FerriteCore, JEI, JourneyMap и др.).
  - Живой поиск, категории (Моды, Модпаки, Шейдеры, Ресурспаки), переключатели установки.
  - **Добавить нативный мод с GitHub**: поле ввода репозитория и кнопка добавления напрямую.
- **Вкладка «Серверы»**:
  - Стартовый блок: *«Серверов пока нет. Создайте его: это займёт несколько секунд...»*.
  - Кнопки создания сервера и добавления папки.
  - Модальное окно конфигурации (название, ядро Paper/Fabric/Vanilla, порт, принятие EULA).
  - Управление созданными серверами (Запуск/Остановка, статус, копирование IP в 1 клик).
- **Вкладка «Гардероб»**:
  - Интерактивный 3D-рендер персонажа (вращение мышью, анимация походки).
  - Пресеты скинов (Steve, Alex, KBL Cyber) и загрузка своего `.png`.
  - Выбор плащей KBLauncher Founder, Migrator.
- **Вкладка «Версии»**:
  - Таблица доступных релизов и сборок с кнопками скачивания/удаления.
- **Вкладка «Список изменений»**:
  - Полный чейнджлог версии 0.2.42 Nightly.
- **Боковая панель «Сборки»**:
  - Список сборок с индикатором *«● Готово»*.
  - Кнопка создания новой сборки (`+`).
  - Кнопка **«Вступить в Discord»**, **«♡ Поддержать»**, **«🌐 Сайт»**, версия *«Лаунчер 0.2.42»*.

## 🚀 Запуск лаунчера

### Способ 1: Прямой запуск (Windows)
Просто запустите файл:
```bat
run.bat
```
или выполните в консоли:
```powershell
npm start
```

### Способ 2: Запуск в браузере (Web-превью)
```powershell
npm run web
```
Затем откройте в браузере: `http://localhost:3000`
