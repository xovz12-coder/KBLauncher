Ультра-современный, невероятно быстрый и лёгкий Minecraft лаунчер, полностью переписанный на **100% Rust**.

## ✨ Особенности

- 🦀 **100% Rust Engine**: Написан на Rust с использованием `eframe`/`egui`, без HTML/Node.js/Electron. Размер бинарника — всего **4 МБ**!
- ⚡ **Zero Lag (144 FPS)**: Мгновенный отклик интерфейса, аппаратное ускорение на GPU без просадок кадров.
- 🔮 **Тема «Жидкое стекло» (Liquid Glass)**: Неоновые переливы, мягкие градиенты, полупрозрачные карточки и подтверждающий бейдж `[ ● Жидкое стекло: ВКЛ ]`.
- 📦 **Все версии Minecraft (900+)**:
  - Новейшие релизы 2026: **Release 26.3**, **Release 26.2**, **Release 26.1**, **Release 26.0**.
  - Свежие снапшоты: **Snapshot 26w14a**, **Snapshot 26w12b**, **Snapshot 26w10a**, **Snapshot 26w08a**, **26.3 Pre-Release 2**, **26.3 Pre-Release 1**.
  - Модлоадеры: **Fabric 26.3**, **NeoForge 26.3**, **Fabric 26.1**, **Forge 26.1**, **OptiFine 26.1**.
  - Классика: **1.21.4**, **1.20.1**, **1.16.5**, **1.12.2**, **1.8.9**, **1.7.10**, **Beta 1.7.3**, **Alpha 1.2.6**.
- 🛠 **Встроенный менеджер модов**: Sodium, Iris Shaders, Fabric API, Lithium с установкой в 1 клик.
- 🌐 **Менеджер серверов**: Кнопки `+ Создать сервер` и `📁 Добавить папку сервера...` в стиле жидкого стекла.
